## &nbsp;`01` &nbsp;About

현장의 「수작업」을 실제로 돌아가는 시스템으로 바꾸는 엔지니어입니다.

요구사항 정리부터 설계, UI·API·DB·AI 연동, 결제, 인프라 구축, 운영까지 **혼자서 끝까지 만들어내는 것**이 강점입니다.
일본어·한국어·영어로 개발과 클라이언트 커뮤니케이션이 가능합니다.

## &nbsp;`01` &nbsp;About

現場の「手作業」を、動くシステムに置き換えるエンジニアです。

要件のヒアリングから設計、UI・API・DB・AI 連携、決済、インフラ構築、運用まで、**ひとりで最後まで作り切る** ことを得意としています。
日本語・韓国語・英語で開発とクライアント対応ができます。
